# As Melhores Anos 90 — versão pronta para upload

## Como subir

Envie todos estes arquivos para a raiz do seu projeto Netlify:

- `index.html`
- `style.css`
- `index.js`
- `player.js`
- `playerElements.js`
- `utils.js`
- pasta `data/`
- sua pasta original `files/` com todos os `.mp3` e imagens

A pasta `files/` deste pacote está vazia de propósito. Coloque nela os mesmos arquivos de áudio e capas que você já usa hoje.
